# ZORU Miner 1.5.7

Wallets created with the original ZORU encrypted wallet format can now be unlocked using the existing password. On successful unlock, the application preserves an encrypted copy of the original wallet and migrates the active keystore to Web3 v3 without changing the wallet address.

Financial values in the desktop application now use exactly one thousands separator. Debian packages include the original GUI command alias for older desktop shortcuts, along with a local shortcut cleanup command.

This update keeps the current ZORU mainnet deployment on VEX EVM chain 6736. Existing mining journals and reward history are unaffected.
